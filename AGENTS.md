# Preferências de trabalho

- Quando o usuário disser "salvar", revisar as alterações e criar um commit Git local.
- Usar mensagens de commit em português, com título claro e descrição coerente com as alterações realmente realizadas.
- Executar as verificações disponíveis e relevantes antes do commit e informar eventuais limitações.
- Não fazer push sem solicitação do usuário.
