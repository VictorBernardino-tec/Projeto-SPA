# Projeto SPA

## Sobre o projeto

Este projeto é uma Single Page Application (SPA) desenvolvida para praticar conceitos de desenvolvimento front-end utilizando HTML, CSS e JavaScript.

A aplicação permite navegar entre as seções Início, Projetos e Contato sem carregar diferentes páginas HTML. O conteúdo é atualizado dinamicamente através do JavaScript e da manipulação do DOM.

O projeto também possui geração dinâmica de cards, formulário de contato com validação, armazenamento de dados no localStorage, modularização do JavaScript e integração com a biblioteca SweetAlert2.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- SweetAlert2

## Funcionalidades

- Navegação SPA utilizando hash na URL
- Alteração dinâmica de conteúdo através do DOM
- Geração dinâmica dos cards de projetos
- Delegação de eventos
- Formulário de contato
- Validação de nome e e-mail
- Armazenamento de dados com localStorage
- Recuperação dos dados salvos
- Notificações com SweetAlert2
- JavaScript organizado em módulos ES6
